# EpicBloxs

EpicBloxs is a browser-based multiplayer game platform with blocky worlds, player avatars, chat, and community-created games.

## Features

- Play the built-in games directly in the browser, with smoother movement, sprinting, jumping, and player-shaped NPCs.
- Built-in games include player health, working melee/ranged weapons, enemy pathing, animated NPCs, and game-specific objectives.
- Zombie Survival has nighttime waves, a weapon shop, and spatial obstacle avoidance; Castle Defense has attacking raiders and a central tower.
- Neon materials and emitted light are used in suitable game worlds, including Neon City and Lava Escape.
- Customize avatars with a broader skin-tone palette.
- Save favorite games locally, and browse games by popularity or Sunnys earned.
- Rate games and post comments from each game's detail page.
- Use emoji in room, direct, and group chats.

## Run locally

Install dependencies with `npm install`, then start the app with `npm start`. Runtime data and secrets are created in the ignored `data/` directory.
