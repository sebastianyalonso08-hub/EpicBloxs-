# EpicBloxs V19

Mejoras de juegos y música.

- Música procedural con acordes, bajo, melodía y variaciones por juego.
- Zombie Survival: enemigos móviles y oleadas progresivas.
- Treasure Island: cofres interactivos con E y recompensas.
- Lava Escape: lava ascendente con avisos y reinicio al alcanzarte.
- Se conserva el resto del sistema del V18.
